Unidade Orçamento Gasto Disponível planejado % utilizado

Saldo por unidade reflete orçamento por setor (VN/FROTA/VU/SG) menos custos diretos de mídia digital, menos custo compartilhado de site/design rateado igualmente entre as lojas de cada marca, menos propaganda/eventos/ materiais de marketing reais de julho, agosto e setembro (importados do ERP), menos lançamentos manuais. Rádio, TV, outdoor, PDV, patrocínios, endomarketing, reserva e verba cooperada ainda não têm valores individualizados para os demais meses — lance-os manualmente pelo botão "Lançar gasto" conforme forem ocorrendo. Ao lançar um gasto que cobre várias lojas de uma marca (ex: uma fatura única de mídia), use "Ratear entre unidades": os modelos automáticos usam a mesma participação por loja já usada no rateio interno de mídia da planilha de origem, e é possível salvar divisões personalizadas para reutilizar depois. Base: Orçamento MKT Todas Marcas/Lojas, Investimento 2026 e exportação do ERP (propaganda/eventos/materiais jul–set) enviados pelo usuário.       Preencher gasto de mídia automaticamente
      Considera o custo mensal de mídia digital (Google, Meta, TikTok, BV...) como gasto fixo em todos os meses de jul a dez, mesmo os futuros — é um custo recorrente já contratado.

      Sincronização com Google Drive

      —

      1. No Google Cloud Console, crie um Client ID OAuth do tipo "Aplicativo da Web".
      2. Em "Origens JavaScript autorizadas", adicione o endereço onde este arquivo ficará publicado (ex: https://grupoorletticrm.github.io).
      3. Ative a API do Google Drive no projeto.
      4. Cole o Client ID acima e clique em "Conectar Google Drive".

      Backup manual

      Sem o Drive configurado, os lançamentos ficam salvos apenas neste navegador. Exporte um backup regularmente.
